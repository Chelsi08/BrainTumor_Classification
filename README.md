# Brain Tumor Classification 🧠

This project uses a Convolutional Neural Network (CNN) to classify brain MRI images into tumor and non-tumor classes.

## Files
- `mainTrain.py` – Python script to train and evaluate the model
- `BrainTumor10epochsCategorical.h5` – Trained model file
- `.eps` files – Visualization outputs (accuracy, loss, confusion matrix, ROC curve, random predictions)
